# 开发大纲

原生版与网页版并行。网页版照旧是正式版，原生版一块一块追上来。
每一阶段结束时都是一个能交给测试用户的版本。

排序的原则：
1. 先做「每天都用」的，后做「偶尔打开」的；
2. 先做不花钱、不出错就不会坏事的，再做会自动调接口的；
3. 每一块都带自动测试；会调接口的，先写「接口一直失败时打出去几次」的测试。

---

## 阶段 0：底层与骨架（已完成）

- 本地库：装下网页版全部数据域，不认得的字段原样留着
- 导入网页版备份：ZIP、纯数据、加密，失败不动已有数据
- 接口层：Anthropic 与 OpenAI 兼容，流式，重试与换接口默认关，每次请求记账
- 提示词：模板由脚本从网页版生成；一对一聊天按网页版默认布局拼装
- 回复解析：标记正则照抄网页版
- 界面：消息列表、一对一聊天、接口设置、用量与上限、问题反馈
- 问题反馈：诊断记录与导出，不含聊天内容与密钥
- 自动测试，推送即编译（到 2026-10-13 共 69 项）

服务器到点调接口，再推送通知。原生版接同一个服务器，交接规矩照网页版 ARCHITECTURE 4.242：
