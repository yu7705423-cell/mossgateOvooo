# 聊天 app 逐项对照：网页版 vs 原生版

核对日期：2026-10-14。网页版以 `yu7705423-cell/phone` 的 `src/apps/chat`、`src/system/ai` 为准，原生版以本仓库 `dev` 分支为准。
每一条都在原生代码里找过：找到对应代码的才标「已做」，做了一半的写明缺什么，找不到的标「未做」。

状态记号：**✓ 已做**　**◐ 部分**　**✗ 未做**　**＋ 原生独有**

做完一项就在这里改状态。「聊天做完了」指这份清单全部是 ✓（依赖别的 app 的那几项除外，见第九部分）。

---

## 一、会出错的地方（先修）

| 项 | 现状 |
|---|---|
| 「现状」区块（关于你、关于自己、最近、进行中的事） | ✗ 记忆总结会写，但从不放进提示词；召回又排除了进行中的事。角色读不到进行中的事 |
| 单聊历史里角色旧消息的译文 | ✗ 群聊补 `[译文：…]`，单聊不补；也没有末尾那句翻译提醒。网页版注释里写明掉翻译多半因为这个 |
| 认不出的整行标记 | ✗ `[去电]` `[视频去电]` `[存图：…]` `[撤回动态]` `[暂停]` `[继续]` `[倒回：…]` `[同行]` `[不去]` `[开设情侣账户]` `[批准]` `[驳回]` `[全员禁言]` `[解除全员禁言]` `[覆盖]` `[不覆盖]` 会原样变成一条文字气泡（导入的历史里有，模型可能照着写） |
| 群里的 `[私信：…]` | ✗ 直接落成群消息，没有转去私聊 |
| 标记名写成繁体 | ✗ 不认（网页版 foldMarks） |
| 状态栏那一段 | ✗ 不从回复里剥出来，会混进正文 |
| 自动分条字数 | ◐ 写死 40 字，不读「autoSplitAt」，填 0 关不掉 |
